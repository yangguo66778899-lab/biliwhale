## 2. 和上一版比，改了什么

### 文案（§5.1）

- **每个字段都换成了「动词/名词短语 + 数量与范围」**，小字写在下面说明后果。举例：
  - 「温度」→「想象力（0–2）」小字「越大越发散；0.7 已经够用」
  - 「每日分享上限」→「一天最多发几条（0–10）」小字「设到 3 以上会提醒一次」
  - 「一律预演」→「只演练，不真发」小字「开 = 所有写操作只打印（内部字段 safety.dryRun）」
  - 「主人 UID」→「你的 UID（主人）」小字「必填，而且必须是另一个号：评论 @ 谁、私信发给谁、聊天只回谁，都看它」
- **分组标题也换了**：程序行为 → 程序本身；DeepSeek → 模型与花费；账号 → 两个号；偏好 → 她爱看什么；
  作息 → 什么时候醒；选题 → 一轮看多少；分享 → 对外发言（评论 / 私信）；监听与回复 → 收消息与回复。
- **面板上不出现英文枚举**：`full/brief/off`、`auto/light/dark`、`comment/dm` 等都只显示中文名
  （枚举的中文显示名放在 `spec.ts` 的 `valueLabels` 里，写回配置仍是英文）。
- **删掉了 22 个「点了没用」的字段的显示**（不是删字段，老配置照常能读）：见
  [`docs/文案对照表.md`](../文案对照表.md) 最后一节，每个都写了为什么先藏起来。
  其中最显眼的是「收藏夹选题源」「全天监听」「只认主人」「日志脱敏」这些还没接线的开关。
- **「配色」原来是个没接线的死开关，现在真的生效**：`/api/session` 带上 `ui.theme`，页面一打开就按它上色
  （不用先进设置页），`auto` 跟着系统。

### 视觉（§5.2，ark depth 2）

- **语言**：黑白 + 单一青色强调（`#5FE0D8`），只给「当前 / 可点 / 进度」；破坏性操作用红，状态用绿/黄/红配文字。
- **布局**：桌面 1200 上限居中、左窄导航 200px + 右内容；窄屏（<820）导航变顶部横条。
- **tokens 全部落地**：间距只用 4/8/12/16/24/32；圆角只有 2px；字号 24/16/14/12，数字一律等宽；
  动效只有 120ms 淡入 + 上移 6px，并遵守 `prefers-reduced-motion`。
- **没有**六边形、扫描线、噪点、假终端输出、外链字体（离线可用这条仍有不变式测试守着）。

## 3. 怎么自己验

1. `npm run serve`，打开打印出来的地址（或托盘「打开面板」）。
2. 设置页从上往下扫：每个字段的**大字是「在问什么」**，**小字是「改了会怎样」**；右上角「配色」切一下深浅。
3. 把浏览器窗口拉到很窄（≈390）：导航变成顶部横条、卡片不横向滚动、长路径会换行。
4. 键盘 Tab 走一遍：焦点框是 2px 青色，从导航到按钮都能到。

## 4. 已知的测量限制（诚实记录）

- 这台机器上 Edge 无头模式**最小视口约 504 CSS px**（`--window-size=390` 会被系统最小窗口宽度顶住），
  所以「390 宽的截图」拿不到真正的 390 视口；`prototype-overview-narrow.png` 是 504 宽。
- 窄屏的横向溢出是用**测量脚本**确认的（viewport 504 时 `documentElement.scrollWidth` = 489，没有页面级横向滚动；
  唯一超出视口的是导航条内部的横滚，属于设计如此），不是靠眼睛猜的。
- 长路径/长 URL 撑宽页面这个问题就是这轮测量发现并修掉的（`td/.mono/a` 加 `overflow-wrap: anywhere`）。
