## 5. M1 期间修掉的问题

1. **`state.json` 半截字段崩溃**：`AppStateStore.get()` 之前直接读 `state.budget.date`，手改/旧版本文件会让守护进程起不来。现在先 `normalize()` 补默认值。
2. **重算后不立即补跑**：开机/恢复/改配置时新计划可能已经到点，原来要等下一个 30s tick。现在重算后同一 tick 里再判一次（文档 §7.2 休眠恢复的要求）。
3. **`reg.exe` 起不来时自启失败**：`execFile` 在受限环境同步抛错，Promise 永不 resolve；现在兜住并回落启动文件夹。
4. **参数属性 / enum 没人拦**：`tsc` 能过、`node` 直接崩（M0 已经踩过一次）。现在有不变式测试扫源码 + 逐个 `import` 所有 `src` 模块。
5. **`.ps1` 编码**：无 BOM 时 PowerShell 5.1 按 GBK 读，中文注释把引号配对搞乱 → 语法错误。现在构建脚本带 BOM，并有测试守着（`.json` 反过来必须无 BOM）。

## 6. 刻意没做

- **崩溃自愈**（重启退避 1s/5s/30s/2min、1 小时 5 次后停、托盘标红、`crash.log`）：文档把这件事归给「壳/计划任务」，M1 只做到托盘显示「内核没在跑」。留 M5/M6。
- **CSRF token**：M1 的鉴权是 Bearer（状态页把 token 放 URL，请求带 header），没有 cookie 会话，CSRF 不成立；M2 引入正式面板与 cookie 时再补。
- **写操作**：仍然为零。M3 才有评论/私信/收藏/动态/点赞，M4 才有监听与聊天。
- **托盘图标**：用的是系统默认图标（`SystemIcons.Application`），没有画自己的 ico（M5 打包时一起做）。
