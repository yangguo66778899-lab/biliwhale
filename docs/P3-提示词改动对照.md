# P3 提示词改动对照（2026-10-24）

> 这一轮只改「说话」三处（评论 / 日记 / 动态）和一个聊天模板，不动约束黑名单之外的结构。
> 下面每一条都给出**改前原文**和**改后原文**，方便你逐句判断。

## 1. 日记开头不再暗示「晚上」

文件：`src/orchestrator/prompts.ts` · `buildDiaryPrompt`

**改前**

```
一段给主人看：像晚上想起今天看到的一件事，随手记下来。只有一件事也行，写不完整也行。
```

**改后**

```
一段给主人看：想起今天看到的一件事，随手记下来。只有一件事也行，写不完整也行。
```

为什么：lab 跑了 9 轮，**每篇日记都用「晚上想起 / 晚上突然想起」开头**——模型把示例里的时间抄成了模板。
删掉时间提示，让它自己决定什么时候想起。

## 2. 日记明确「不用交代视频讲了什么」

文件：`src/orchestrator/prompts.ts` · `buildDiaryPrompt`

**改前**：无这一条。

**改后**（新增）

```
- 不用交代视频讲了什么，写你想到的那一点就够了。
```

为什么：工具箱那条日记有 70% 在复述路径和摘要截断——它把「看完的感受」写成了「视频内容摘要」。

## 3. 三条「说话」共用的规矩（原来散在三处、措辞还不一样）

文件：`src/orchestrator/prompts.ts` · 新增 `voiceRules()`；评论 / 日记 / 动态三处都调用它

**改前（三处各自为政）**

| 位置 | 原文 |
|---|---|
| 评论 | `- 少用影评腔（剪辑、节奏、信息密度、立意）——除非视频本身就在讲这些。` |
| 日记 | `- 别总结，别升华，别下结论。想到哪儿写到哪儿。`<br>`- 别写今天看了几条、几分、候选、素材这类账。` |
| 动态 | `- 不 @ 任何人；不带链接；不写「本轮/候选/评分/额度」这类账。` |

**改后（统一成四条）**

```
- 想到哪儿写到哪儿；不要在结尾总结、升华、下结论。
- 少用影评腔（剪辑、节奏、信息密度、立意、叙事），除非视频本身就在讲这些。
- 别用「总的来说」「不得不说」「值得一提的是」「其实不然」这种开头。
- 不写「本轮/候选/评分/阈值/token」这类账。
```

为什么：三处说法不一致，模型就会挑最松的那处学；另外新增了「别用 AI 腔开头」这一条
（不是长黑名单，只点了四个最常见的起手式，避免误杀正常表达）。

评论还保留它自己的两条（「写你看到这儿想到什么，不是写评语」「别编具体人名地名」）。

## 4. 聊天提示词抽成文件，并用人设

文件：`src/prompts/chat.md`（新）、`src/orchestrator/chat.ts`

**改前**：规则写死在 `chat.ts` 的数组里，且**只用了配置里的名字/称呼/自称，没有读人设文档**。

**改后**：
- 规则移到 `src/prompts/chat.md`（`{{maxChars}}` 占位）；
- 人设文档在规则之前整段注入；
- 名字没填时不再渲染成「你是「」」，直接写「你在和主人私下聊天。」

为什么：日记/评论已经用上人设了，聊天还停在「名字 + 称呼」，同一个人三张嘴。

## 4.5 日记 few-shot：用户提供的 9 篇（2026-10-24 换掉旧的两篇）

文件：`src/prompts/examples/diary-samples.md`（新）+ `buildDiaryPrompt`

**改前**：日记提示词里**没有任何正例**；清单 §7.6 里的两篇（油泼面 / 出租屋）只躺在文档里。

**改后**：把用户 2026-10-24 给的 **9 篇**（黏土蛋糕、速写、极光、纸箱猫别墅、二胡、物理实验、徒步、大肥鱼、雨林音频）
一字不改地放进提示词，位置在「# 就这样写」之后、输出契约之前，并配 5 条使用说明：

1. 学写法，不学事实；
2. 没给画面就别写画面细节（反应可以写，事实要有来源）；
3. 不写「字幕里说…」这种来源标注；
4. 工具做不到的动作换成真做过的，或者删掉；
5. 真正做过的事只有：看视频、评论、点赞、发动态、跟主人说话——截屏、下载、搜索别写成做过。

为什么换：旧的两篇是「记录 + 自我修正」的写法，用户新给的 9 篇更活（自嘲、闹主人、承认听不懂、结尾落在生活动作上），
而且覆盖了 9 种情绪，few-shot 的示范面更宽。

效果（同一批材料、3 条 × 2 轮）：
- 日记里「晚上想起…」的模板开头**消失**；
- 出现「我连手都没有」「管它有没有道理」「去刷点小狗视频缓一缓」这类自嘲与生活动作收尾；
- 日记 96–172 字，没有为凑长度灌水；自检全过。

## 5. 面板上的两处文案（顺带）

| 位置 | 改前 | 改后 |
|---|---|---|
| 概览「今日」行 | `醒 1/1 次 · 分享 0/3 条` | `醒 1/1 次 · 分享 0/3 条 · 动态 今天还没发（上限 1）` |
| 「发动态…」弹窗标题 | 发一条动态 | 发一条动态（手动） |
| 弹窗说明 | 只有「发出去只能整条删掉…」 | 多一句：这是手动发的一条，和每天定时那条分开记：手动发不占「一天一条」的名额，但同样会过写开关和风控 |

## 没有改的

- 黑名单（清单 §7.5 那份长表）：**没有照搬**——只取了四个 AI 腔开头，其余靠自检与示例。理由：约束越长，模型越像填表。
- 「重写一次」：代码在，`round.ts` 里仍是 `allowRewrite: false`，等你看完这版再开。
- `task`/`report_md` 的输出契约：不动。
