# 文案对照表（P1 界面重做）

> 用途：清单 §5.1 要求的交付物之一——**逐个字段**对照「改之前长什么样」和「现在长什么样」。
> 覆盖方式：这张表由脚本从 `src/config/spec.ts` 机械生成（改前的版本从 git 取出对照），
> 所以「面板上看得见的字段」是 100% 覆盖；`hidden` 的字段单独列在最后。
> 读法：「现在（技术）」= P1 之前的 label/desc；「改成（人话 + 小字）」= 现在面板上的大字与小字。

- 面板上看得见的字段：**127** 个
- 面板上不显示的字段（还没接线，见文末）：**22** 个
- 校验：`test/ui-copy.test.ts` 会检查「每个可见字段都有中文标题 + 一句小字」「枚举必须有中文显示名」「hidden 字段真的不出现在面板上」

> **v1.13（日更动态）改动 3 个字段**（「发动态」组）：
>
> | 字段路径 | 之前 | 现在 |
> |---|---|---|
> | `dynamic.enabled` | 允许发动态（一轮里永远不会自动发；只能面板手动） | 允许发动态（每天固定时间自己写一条；也可面板手动） |
> | `dynamic.dailyTime` | （新增） | 每天几点发（HH:MM），默认 00:00 |
> | `dynamic.minChars` / `dynamic.maxChars` | （新增） | 至少/最多写几个字（100–1000），到上限会截断 |

## 面板上不显示的字段（还没接线）

这些字段还在 `spec.ts` 里（老配置照常能读、导出照常带），只是**不摆到面板上**——
摆出来就是「点了没用」的假开关（P0-1 的教训）。等真接上线再去掉 `hidden`。

## 怎么复核

1. 打开面板「设置」页，随便挑 10 个字段：能不能一眼说出「这一栏填什么、改了会怎样」。
2. 对照这张表看「小字」在面板上是不是真的显示了（每个字段下面那行灰字）。
3. 面板上搜不到「webhook / command / format / template / dryRun」这类英文枚举（通知的高级区展开后才出现中文名）。
