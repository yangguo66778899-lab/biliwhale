# BiliWhale 用户手册

> 这份是「怎么用」；「怎么改代码」看 [`ARCHITECTURE.md`](./ARCHITECTURE.md)，逐条验收看 `M0`–`M5` 验收记录。
> 版本：`0.7.0-M5` · 平台：Windows 10/11（x64）

---

## 1. 它是什么

一个常驻在你自己电脑上的 B 站「养鱼」程序：按它自己的作息醒来，去 B 站读视频、判断值不值得，
写一份日报和两本日记；该分享的，用**一条评论 @ 你**或**一条私信**告诉你。它只调用 DeepSeek。

它**不是**：刷量工具、评论机器人、代你社交的账号托管。所有对外写操作默认关闭，打开后也有闸门与额度；
撞风控会立刻停手。

## 2. 装（两条路，都不用管理员）

### 2.1 便携版（最快，不写系统）

1. 解压 `BiliWhale-<版本>-portable.zip` 到任意目录（别放 `C:\Program Files`，那里要管理员；**路径里有空格或中文也没关系**）
2. 双击 `BiliWhale.cmd`
3. 几秒后面板自己弹出来（**不用再去点托盘**）：托盘起来 → 内核没起就自己拉起 → 开一个没有地址栏、没有标签页的窗口

包里有 `runtime\node.exe`，**不需要你装 Node**。数据不在这里，在 `%APPDATA%\BiliWhale`。

**用起来要知道的三件事**：
- **关窗口 ≠ 退出程序**：那个窗口是单独一个进程，关掉它以后托盘还在、到点照常醒。想再打开：托盘右键「打开面板」，或**再双击一次图标**。
- **再双击一次**只会把已经开着的窗口带到前面，不会起第二个内核、也不会多一个托盘图标。
- 窗口用系统 Edge 的 app 模式（像一个真程序）；机器上没有 Edge 就退回默认浏览器（会带地址栏，但功能一样）。

### 2.2 装到开始菜单（推荐长期用）

1. 解压后双击 `install.cmd`
2. 它会：
   - 复制程序到 `%LOCALAPPDATA%\Programs\BiliWhale`
   - 设用户环境变量 `BILIWHALE_KERNEL_CMD`（托盘用它拉起内核）
   - 建开始菜单快捷方式（要桌面图标：`install.cmd --desktop`）
   - 要开机自启：`install.cmd --autostart`（只起托盘，不弹窗、不抢焦点）
   - 最后启动托盘（不想它自动启动：`install.cmd -NoLaunch`）
3. 想改安装位置：`install.cmd -Target D:\Apps\BiliWhale`

**卸载**：双击 `uninstall.cmd`。默认**保留数据**；连数据一起删：`uninstall.cmd --remove-data`。

### 2.3 不想装/没有虚拟机：拿一个普通文件夹当「假机器」

`install.ps1` 有个 `-NoRegister` 开关：**只复制文件**，不写注册表、不建快捷方式、不改环境变量、不启动。
所以想先确认「这个包在我机器上能不能装、能不能跑、卸了数据还在不在」，不用虚拟机也不动系统：

```powershell
# 1) 把 zip 解压到一个临时文件夹，比如 D:\BiliWhale-test\portable

# 2) 「试装」到另一个文件夹（只复制，不碰系统）
powershell -NoProfile -ExecutionPolicy Bypass -File D:\BiliWhale-test\portable\install.ps1 `
  -NoRegister -Target D:\BiliWhale-test\installed

# 3) 直接跑装好的那份（用的是你自己的数据目录；想隔离就加 --data-dir）
D:\BiliWhale-test\installed\BiliWhale.cmd

# 4) 「试卸载」：只删那个目录，数据不动
powershell -NoProfile -ExecutionPolicy Bypass -File D:\BiliWhale-test\portable\uninstall.ps1 `
  -NoRegister -Target D:\BiliWhale-test\installed
```

验完把 `D:\BiliWhale-test` 整个删掉就行——系统里什么都没留下。
（开发机上还可以一条命令自动走完这套：`npm run rehearse`，见 `docs/M5-验收记录.md` §9。）

**另一种更省事的验法**：完全不装，解压后直接双击 `BiliWhale.cmd` 用便携版。
它和安装版是同一份程序，只是没有开始菜单图标和开机自启。

## 3. 第一次用（5 分钟）

| 步 | 在哪 | 做什么 |
|---|---|---|
| 1 | 面板「账号」 | 扫码登录 **B 站小号**（这是「鲸鲸」自己的号，不建议用主号） |
| 2 | 面板「账号」 | 填 **主人 UID**：你自己的另一个 B 站号（`space.bilibili.com/你的UID` 里那串数字）。**必填，且不能等于登录账号**——@、私信、聊天都发给它 |
| 3 | 面板「设置 → DeepSeek」 | 填 API key（也可以用环境变量 `BILIWHALE_API_KEY`）。没 key 时预演也跑不了模型 |
| 4 | 面板「概览」 | 点「预演一轮」：不联网写任何东西，只把这一轮会发生什么给你看 |
| 5 | 面板「设置 → 分享」 | 看完预演觉得行，再打开「允许对外分享」 |

> 为什么必须两个号：程序要能「发」也要能「@ 到人」。用同一个号的话，评论会变成 @ 自己、私信发给自己、
> 聊天永远收不到你的消息——所以现在缺主人 UID 时，相关功能会**明确拒绝**而不是凑合。

## 4. 面板九个页面

| 页 | 能干什么 |
|---|---|
| 概览 | 状态、下一次唤醒、今日额度与花费、最近一轮；预演 / 跑一轮 / 暂停恢复；体检表 |
| 设置 | 全部字段可改（大字是「这一栏在问什么」，小字是「改了会怎样」）；没有接线的开关不会显示出来；保存即生效（schedule 改动会立刻重算计划） |
| 账号 | 扫码登录、粘贴 cookie、复核、退出（只清本机）、UID 与凭据指纹、主人 UID |
| 报告 / 日记 | 按日期看 Markdown；日记分「给你看的」和「给自己看的」 |
| 待审 | 陌生人回复的草稿：「发 / 预演 / 不发」，7 天没处理自动作废 |
| 私聊 | 私信状态、聊天记录（可清空）、手动发测试消息 / 今天的公开日记 / 今天的视频信息 |
| 日志 | 事件流（按级别过滤）+ 下载脱敏诊断包 |
| 关于 | 版本、数据目录、模型、预算、**检查更新**、**备份数据**、退出内核 |

**配色**：「设置 → 面板 → 配色」可以选「跟着系统 / 深色 / 浅色」。选完保存，页面立刻换；
下次打开面板也会按你选的来（不用再进设置页）。

**哪些设置不会显示？** 还没接线的功能（比如「收藏夹选题源」「全天监听」「只认主人」）不会摆到面板上，
免得你点了一个没反应的开关。字段本身还在配置里，老配置照常能读；每个字段的现状见 [`文案对照表.md`](./文案对照表.md)。

**面板怎么打开**：双击桌面/开始菜单图标（会自己拉起内核并开窗口）、托盘右键 →「打开面板」、
或者用 `runtime.json` 里的 `?token=` 地址粘进浏览器。
用 token 打开一次后，内核会给这个浏览器种一个 HttpOnly 会话 cookie（7 天、仅本次进程有效）；
内核重启后旧 cookie 失效，从托盘再点一次即可。空白页先 `Ctrl+F5`。

## 5. 开关与闸门（默认全关，别一次全开）

**总开关**：`设置 → 安全 → 允许写操作`（默认开）与 `一律预演`（默认关）。
`一律预演` 打开时，所有写操作只打印不发送——调试期建议打开。

| 能力 | 默认 | 判据 / 限制 |
|---|---|---|
| 评论 @ | **关** | 分数 ≥ 阈值、只从深读过里挑、每日额度、同视频 7 天、沉默衰减、风控冷却；发前查重（幂等键），发后复核 3 次，没复核上标 `unverified` 且**不自动重发** |
| 收藏 | **开**（账号内低风险） | 理由 ≥6 字、同类 ≥2 条要说明「比它们好在哪」、每日 ≤3、同视频 30 天 |
| 点赞 | 关 | 只点深读过的、每日 ≤5 |
| 动态 | 关 | **一轮里永不自动发**；只能面板手动 + 二次确认；每日 ≤1 |
| 私信分享 | 关 | 一轮合并成**一条**、≤500 字、最多 5 条视频，占分享额度 |
| 私聊通知 | 关 | 摘要 / 今天的公开日记 / 视频信息，三个子开关独立；视频信息只用本轮已有数据，不额外请求 |
| 评论/@ 监听 | 关 | 间隔 ≥60s + 抖动，空闲退避到 15 分钟；第一次只建基线（不倒历史）；陌生人进「待审」 |
| 私信监听 + 聊天 | 关 | 只认主人；每条来信最多回 1 条、≤20 条/小时；不调工具、不改配置、不触发分享 |

**聊天能做什么**：陪你聊、发一条今天的公开日记、发一条今天上下文里的视频信息。
**不能做什么**：改设置、贴 cookie、发别的视频/链接、群发、替你操作账号——越界请求会被固定话术拒绝。

## 6. 备份、升级、回滚

### 备份

- 面板「关于 → 备份数据」，或命令行：
  ```
  runtime\node.exe app\src\cli.ts backup
  runtime\node.exe app\src\cli.ts backup --data-only      （不要报告/日记，只要配置与账本）
  runtime\node.exe app\src\cli.ts backup --with-secrets   （连登录凭据一起，注意存放）
  runtime\node.exe app\src\cli.ts backup list --from <zip>（看看里面有什么）
  ```
- 默认存到 `<数据目录>\backup\BiliWhale-backup-<时间>.zip`；默认**不含**凭据（恢复后要重新登录）。

### 升级

1. 先备份（上面）
2. 退出内核：托盘右键 → 退出（或面板「关于 → 退出内核」）
3. 用新包覆盖：便携版直接解压覆盖；安装版再跑一次 `install.cmd`
4. 打开面板确认版本；日志里会写「配置已从 v1 迁移到 v2」这类记录

**配置迁移**只补字段/改形状，**不导入旧数据**；迁移失败会保留原配置并报错，不会把设置冲成默认值。

### 回滚

装回旧版的 `app\` + `runtime\`，然后用升级前的备份恢复数据：
```
runtime\node.exe app\src\cli.ts restore --from <备份.zip> --yes
```
恢复只认白名单文件（配置/账本/报告/日记/聊天），不会动程序文件。

## 7. 数据在哪

| 内容 | 位置 |
|---|---|
| 配置、凭据、账本、报告、日记、聊天、备份 | `%APPDATA%\BiliWhale` |
| 日志、缓存、心跳、`runtime.json` | `%LOCALAPPDATA%\BiliWhale` |

调试时可以用 `--data-dir <path>` 换数据目录，用 `--fixtures` 完全离线跑（不碰 B 站、不调模型）。

## 8. 出问题了

| 现象 | 先看什么 |
|---|---|
| **双击图标只闪一下就没了 / 托盘没出现** | 看 `%LOCALAPPDATA%\BiliWhale\logs\tray.log`（写不了那个目录时在 `app\shell\tray.log`）。里面记了它走到哪一步、要执行的内核命令；把那条命令粘到命令行跑一次就能看到真正的报错 |
| 托盘一直「内核没在跑」 | 命令行跑 `runtime\node.exe app\src\cli.ts doctor`，把红叉项修掉 |
| 双击后弹了「内核没能起来」 | 按提示框里给的两条命令跑一次；常见原因是包不完整（只解压了一半）或 `%APPDATA%` 没写权限 |
| 面板空白 / 一直「连接中…」 | `Ctrl+F5`；还不行看命令行有没有 401（token 失效 → 从托盘再打开一次） |
| 到点不醒 | 面板「概览」看下一次唤醒时间；设置里窗口的「醒来次数」之和是否 >3（会被校验拒绝） |
| 改了设置没生效 | 保存后面板会提示；schedule 改动 500ms 内重算，其它字段下一次调用生效 |
| 评论发了但只有自己看得见 | B 站会「仅自己可见」（shadowban）。程序会标 `held` 并在之后复核；**不要反复重发** |
| 想看它到底干了什么 | 面板「日志 → 下载诊断包」（脱敏，不含 cookie/key） |

**诊断包里有什么**：版本、系统、配置（脱敏）、体检结果、最近事件、最近一轮的结构化记录。
**没有什么**：cookie、API key、聊天原文。

## 9. 我该多久看一次

- 头一周：每天看一眼「概览」和「报告」，确认评论/私信内容像你说话
- 稳定后：一周一次，看报告与「待审」；额度、花费、复核状态都在概览上
- 换季/换兴趣：改 `设置 → 内容` 的关键词与屏蔽词，或调整作息窗口
